Процедура ПКО_Справочник_RM_СпособыДоставки_Получение_ПередЗаписьюПолученныхДанных(ПолученныеДанные, ДанныеИБ, КонвертацияСвойств, КомпонентыОбмена)
	ВосстанавливаемыеДанные = Новый Соответствие;
	
	Если Не ДанныеИБ = Неопределено Тогда
		
		Для Каждого ТекущаяСтрока Из ДанныеИБ.СоответствиеСкладовВозвратаПрочимСкладам Цикл
			ДанныеСтроки = Новый Структура("СкладУтиль");
			ЗаполнитьЗначенияСвойств(ДанныеСтроки, ТекущаяСтрока);
			ВосстанавливаемыеДанные.Вставить(ТекущаяСтрока.СкладВозврата, ДанныеСтроки);
		КонецЦикла;
		
	КонецЕсли;
	
	Для Каждого ТекущаяСтрока Из ПолученныеДанные.СоответствиеСкладовВозвратаПрочимСкладам Цикл
		
		ДанныеСтроки = ВосстанавливаемыеДанные.Получить(ТекущаяСтрока.СкладВозврата);
		Если Не ДанныеСтроки = Неопределено Тогда
			ЗаполнитьЗначенияСвойств(ТекущаяСтрока, ДанныеСтроки);
		КонецЕсли;
		
	КонецЦикла;
КонецПроцедуры
